# Software-Fj 
El presente proyecto consiste en el desarrollo de un sistema integral de gestión de clientes, servicios y reservas para la empresa Software FJ utilizando el lenguaje de programación Python y aplicando los principios fundamentales de la programación orientada a objetos.
El sistema permite administrar de manera organizada la información de los clientes, los diferentes servicios ofrecidos y las reservas realizadas,
mediante una interfaz interactiva basada en un menú de opciones.

Características principales
Registro y consulta de clientes.
Registro y consulta de servicios.
Creación y administración de reservas.
Confirmación, cancelación y procesamiento de reservas.
Validación de datos y manejo de excepciones.
Registro de eventos y errores.
Demostración automática de operaciones.

Tecnologías utilizadas
Python 3.
Programación orientada a objetos (POO).
Manejo de excepciones.
GitHub.

Archivos del proyecto
software_fj_interactivo.py: contiene el programa principal y el menú interactivo.
demostracion_software_fj.py: contiene la demostración automática de 20 operaciones.

Ejecución del programa
Para ejecutar la aplicación interactiva, abre una terminal en la carpeta del proyecto y utiliza:
python software_fj_interactivo.py
Ambos archivos Python deben permanecer en la misma carpeta para que la demostración automática pueda importarse correctamente.
